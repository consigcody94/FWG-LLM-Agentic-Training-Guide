## 🚀 Quick Start

### 📋 Prerequisites Checklist

```bash
# System Requirements
□ Modern browser (Chrome, Firefox, Edge)
□ Python 3.11+ installed
□ Node.js 18+ installed
□ Git configured
□ 16GB+ RAM (32GB recommended for local LLMs)
□ NVIDIA GPU (optional, but recommended)
```

### ⚡ 5-Minute Setup

```bash
# 1️⃣ Clone the training repository
git clone https://github.com/your-org/FWG-LLM-Agentic-Training-Guide.git
cd FWG-LLM-Agentic-Training-Guide

# 2️⃣ Set up Python environment
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 3️⃣ Install Ollama for local LLM exercises
curl -fsSL https://ollama.ai/install.sh | sh
ollama pull llama3.2
ollama pull mistral

# 4️⃣ Verify installation
python scripts/verify_setup.py
```

### 🎮 First Exercise: Hello Agent

```python
# labs/00-hello-agent/main.py
import ollama

response = ollama.chat(
    model='llama3.2',
    messages=[{
        'role': 'user',
        'content': 'Hello! Introduce yourself as a federal AI training assistant.'
    }]
)

print(response['message']['content'])
```

### 🔗 Protocol References

<details>
<summary><b>🔗 MCP (Model Context Protocol) Quick Reference</b></summary>

```
╔══════════════════════════════════════════════════════════════════════════════╗
║                        MODEL CONTEXT PROTOCOL (MCP)                          ║
╠══════════════════════════════════════════════════════════════════════════════╣
║                                                                              ║
║  PURPOSE: Standardized communication between LLM applications and           ║
║           external data sources, tools, and services                        ║
║                                                                              ║
║  ARCHITECTURE:                                                               ║
║  ┌─────────────┐     ┌─────────────┐     ┌─────────────┐                    ║
║  │   Client    │────▶│   Server    │────▶│  Resources  │                    ║
║  │ (LLM Host)  │◀────│   (MCP)     │◀────│  & Tools    │                    ║
║  └─────────────┘     └─────────────┘     └─────────────┘                    ║
║                                                                              ║
║  CORE CONCEPTS:                                                              ║
║  • Resources: Data sources exposed to LLMs (files, databases, APIs)         ║
║  • Tools: Functions the LLM can invoke (search, calculate, etc.)            ║
║  • Prompts: Reusable prompt templates                                        ║
║  • Sampling: Request LLM completions from server                            ║
║                                                                              ║
║  TRANSPORT: JSON-RPC 2.0 over stdio or HTTP/SSE                             ║
║                                                                              ║
║  EXAMPLE SERVER:                                                             ║
║  ```python                                                                   ║
║  from mcp.server import Server                                               ║
║  server = Server("my-server")                                                ║
║                                                                              ║
║  @server.list_tools()                                                        ║
║  async def list_tools():                                                     ║
║      return [Tool(name="search", description="Search documents")]           ║
║                                                                              ║
║  @server.call_tool()                                                         ║
║  async def call_tool(name: str, arguments: dict):                           ║
║      if name == "search":                                                    ║
║          return search_documents(arguments["query"])                         ║
║  ```                                                                         ║
║                                                                              ║
╚══════════════════════════════════════════════════════════════════════════════╝
```

</details>

<details>
<summary><b>🤝 A2A (Agent-to-Agent) Protocol Quick Reference</b></summary>

```
╔══════════════════════════════════════════════════════════════════════════════╗
║                      AGENT-TO-AGENT (A2A) PROTOCOL                          ║
╠══════════════════════════════════════════════════════════════════════════════╣
║                                                                              ║
║  PURPOSE: Enable AI agents to discover, communicate, and collaborate        ║
║           with each other in a standardized way                             ║
║                                                                              ║
║  CORE CONCEPTS:                                                              ║
║  • Agent Card: JSON metadata describing agent capabilities                   ║
║  • Task: Unit of work with lifecycle (submitted → working → completed)      ║
║  • Message: Communication payload between agents                             ║
║  • Skill: Capability an agent can perform                                    ║
║                                                                              ║
║  AGENT CARD LOCATION: /.well-known/agent.json                               ║
║                                                                              ║
║  TASK STATES:                                                                ║
║  ┌──────────┐   ┌─────────┐   ┌───────────┐   ┌───────────┐                ║
║  │SUBMITTED │──▶│ WORKING │──▶│ COMPLETED │   │  FAILED   │                ║
║  └──────────┘   └─────────┘   └───────────┘   └───────────┘                ║
║        │              │                              ▲                       ║
║        │              └──────────────────────────────┘                       ║
║        │                                             ▲                       ║
║        └─────────────────────────────────────────────┘                       ║
║                                                                              ║
║  JSON-RPC METHODS:                                                           ║
║  • message/send    - Send message, receive response                         ║
║  • message/stream  - Send message, stream response (SSE)                    ║
║  • tasks/get       - Get task status by ID                                  ║
║  • tasks/cancel    - Cancel a running task                                  ║
║                                                                              ║
║  EXAMPLE AGENT CARD:                                                         ║
║  ```json                                                                     ║
║  {                                                                           ║
║    "name": "Research Agent",                                                 ║
║    "description": "Performs web research and summarization",                 ║
║    "url": "https://agent.example.com/a2a",                                  ║
║    "version": "1.0.0",                                                       ║
║    "protocolVersion": "0.3.0",                                              ║
║    "capabilities": {                                                         ║
║      "streaming": true,                                                      ║
║      "pushNotifications": false                                             ║
║    },                                                                        ║
║    "skills": [{                                                              ║
║      "id": "web-research",                                                   ║
║      "name": "Web Research",                                                 ║
║      "tags": ["research", "search", "summarization"]                        ║
║    }]                                                                        ║
║  }                                                                           ║
║  ```                                                                         ║
║                                                                              ║
╚══════════════════════════════════════════════════════════════════════════════╝
```

</details>
